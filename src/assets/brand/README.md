# Marca aprovada — Dilophosaurus

## Master editorial

`dinopad-dilophosaurus-editorial.png` é a única arte-mestre aprovada pela família.
Tem 1042 × 1008 px e preserva a composição completa: pedra em forma de `D`,
crânio, dupla crista, dentes, rachaduras e samambaias.

`npm run brand:build` remove somente o branco conectado às bordas e gera o PNG
transparente e as variantes AVIF/WebP usadas exclusivamente na home. Nenhuma
variante é tingida por tema.

## Regra de uso

- Não usar a marca no shell, favicon, ícones ou controles.
- Não gerar SVG da marca. Um vetor só poderá entrar após aprovação explícita.
- SVG continua permitido para ícones funcionais da interface.
- Explorações anteriores são rejeitadas e devem permanecer fora de `src` e `public`.
